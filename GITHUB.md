# GitHub

Репозиторій: [practice-tracker](https://github.com/SophiiV/practice-tracker).

Версії для лабораторних:

- [Лабораторні 8–10](https://github.com/SophiiV/practice-tracker/tree/lab8-10) — сервер, база даних і робота з frontend.
- [Лабораторна 11](https://github.com/SophiiV/practice-tracker/tree/lab11-v2) — функціональні, модульні та інтеграційні тести.
- [Лабораторна 12](https://github.com/SophiiV/practice-tracker/tree/lab12) — рефакторинг із патернами.

У гілці `main` знаходиться поточна версія. За тегом можна відкрити код конкретної лабораторної.

Рефакторинг виконано у гілці `lab12-design-patterns`. Порівняння з попередньою версією:

```bash
git diff lab11-v2 lab12 -- backend/src backend/tests
```

# Трекер практики

Застосунок для обліку виробничої практики студентів. Василюк Софія, ІПЗ-41.

У застосунку можна зареєструватися, створити направлення на практику, вести щоденник і виставити оцінку. Доступ залежить від ролі: адміністратор, керівник або студент. Також є заповнення договору та щоденника з завантаженням у DOCX і перегляд інструктажу з безпеки.

Frontend написаний на React, backend — на Node.js та Express. База даних — SQLite.

## Запуск

Потрібні Node.js від 22.13, npm і Python 3\. Команди виконуються з головної папки проєкту:

```sh
npm --prefix backend ci
npm --prefix frontend ci
npm --prefix frontend run dev
```

Після запуску відкрити [http\://localhost:5173](http://localhost:5173). Сервер і frontend запускаються разом. База з демонстраційними даними створюється автоматично при першому запуску. Для зупинки — Ctrl+C.

Для входу можна використати такі акаунти:

- адміністратор — `admin@pnu.edu.ua`;  
- керівник — `mykola.pikuliak@cnu.edu.ua`;

Пароль для всіх трьох: `praktyka2026`.

При реєстрації створюється акаунт студента. Направлення додає адміністратор. У вкладці «Звіт» поки зберігаються тільки назва та статус, без завантаження самого файлу.

## Папки проєкту

- `frontend` — сторінки та компоненти інтерфейсу;  
- `backend` — API, логіка роботи й тести; шаблони документів лежать у `backend/templates`;  
- `database` — схема бази та початкові дані;  
- `shared` — спільні поля документів;  
- `diagrams` — діаграми.

Посилання на версії лабораторних — у GITHUB.md. Деталі серверної частини — у backend/README.md.
